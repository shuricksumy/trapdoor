**Tidier pages.** Long tables in pages, and the Server page in sections.

## Pages for long tables

- Clients (OpenVPN and WireGuard), Connected → recently disconnected, Traffic → by client,
  Limits and the Network page's clients show **15 rows per page**, with "1–15 of 24", the
  page buttons and **Rows: 15 / 25 / 50 / 100**; the browser remembers the choice for every
  table.
- The pager shows only when a table has more than 15 rows; a new search or filter goes back to
  the first page. Recently disconnected now pages through the last 30 days, not only the
  newest 20. The Default row of Limits stays on top of every page.

## Server page in sections

- Each block of the Server page is a section of its own, with its own Save: the server's
  settings (Settings / server.conf / Backups), scripts and extra rules, backup and removing it;
  for WireGuard / AmneziaWG also connection, hiding and client defaults.
- The sections are folded; the header says what is set now (e.g. `UDP 1194 · 10.8.0.0/24`,
  *Running*, *restart pending*), and the browser remembers which ones were left open.

## Also

- The API manual (`docs/api.md`) renders as tables on GitHub again, and examples no longer use
  one installation's internal networks.

## Upgrading from 0.8.0

`docker compose pull && docker compose up -d web`: only the web UI changed.
