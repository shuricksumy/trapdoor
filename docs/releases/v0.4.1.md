Show trapdoor inside your dashboard.

- **`TD_FRAME_ANCESTORS`**: sites that may show the web UI in an iframe, e.g.
  `https://admin.example.com` for a dashboard like Homer or your own. Only those may frame it;
  without the setting nothing changes (framing stays refused). On the same domain as the
  dashboard, the login works inside the frame.

## Upgrading from 0.4.0

`docker compose pull && docker compose up -d`. To use it, set `TD_FRAME_ANCESTORS` for the
web service (the compose files pass it through).
