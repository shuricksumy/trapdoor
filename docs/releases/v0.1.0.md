First release of trapdoor, the successor to openvpn-ui: a web UI for your own OpenVPN,
WireGuard and AmneziaWG servers, on one machine or several.

## Servers

- **OpenVPN, WireGuard and AmneziaWG** side by side, as many as you need: e.g. OpenVPN on
  UDP 1194 and TCP 443, a WireGuard and an AmneziaWG server
- **Several machines** from one web UI: other machines run only the VPN and the agent
  (`docker-compose.remote.yml`), connected over TLS with a pinned certificate
- **Servers page**: every server on every machine with its state, clients, connected devices
  and today's traffic; start, stop, autostart on / off, backup, remove
- **Where it runs is always shown**: machine and container on every page, in *Add a server*
  before you create one, and in the stop / remove confirmations
- **Backup and restore**: one server (also to move it to another machine) or everything at
  once, optionally encrypted with a passphrase; `trapdoor restore` for a fresh machine

## OpenVPN

- Setup for a new server: certificate authority, keys, `server.conf` and client template
  with modern defaults (tls-crypt-v2, AES-GCM, TLS 1.2+)
- Works with an existing openvpn-ui directory as it is (certificates, profiles, routes,
  two-factor logins)
- Clients: create, download profiles, revoke / restore, renew (also in bulk), expiry warnings
- Two-factor login per client (authenticator app with QR code, static password)
- Per-client network: fixed address, routes, site-to-site LANs, full tunnel; **named
  networks** (e.g. "Office LAN") given to several clients at once; a **Network** page with
  what every client can reach
- Server settings editor checked by OpenVPN, with diff preview, backups and restart with
  rollback; OpenVPN 2.7 in the image

## WireGuard and AmneziaWG

- Clients with QR codes for the apps; add one or many at once, notes, your own address, the
  device's own key, per-client DNS, allowed IPs, MTU and keepalive; editable later
- Server settings and client defaults (endpoint, DNS, allowed IPs, MTU, keepalive, preshared
  key) editable after creation
- **AmneziaWG** against VPN blocking: obfuscation levels 1.5, 2.0 (default) and 3.1 (header
  protection, random packet sizes and timings); runs in userspace, no kernel module needed
- Changes apply without disconnecting anybody (`wg syncconf`)

## Everywhere

- Live sessions and traffic history by day / month / year per client and per server, CSV export
- Access rules (firewall) per client or for everyone, per server
- Admin login with throttling, no privileges for the web UI, strict CSP; light / dark / auto
  theme; works on phones
- Docker image for amd64 and arm64, kept current (daily rebuild when Alpine has newer
  packages, Renovate for AmneziaWG); Linux binaries
- [Deployment examples](https://github.com/shuricksumy/trapdoor/tree/main/examples): all in
  one, a container per VPN type, remote machines

Install: see the [README](https://github.com/shuricksumy/trapdoor#quick-start-docker).
