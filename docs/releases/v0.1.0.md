First release of tunnelward, the successor to openvpn-ui.

- Setup for a new server: certificate authority, keys, `server.conf` and client template with modern defaults
- Works with an existing openvpn-ui directory as it is (certificates, profiles, routes, two-factor logins)
- Clients: create, download profiles, revoke / restore, renew (also in bulk), expiry warnings
- Two-factor login per client (authenticator app with QR code, static password)
- Live sessions, traffic history by day / month / year per client and for the server, CSV export
- Per-client network: fixed address, routes, site-to-site LANs, full tunnel
- Access rules (firewall) per client or for all clients
- Server settings editor checked by OpenVPN, with diff preview, backups and restart with rollback
- Docker image for amd64 and arm64, compose files for a plain setup and for Traefik; Linux binaries

Install: see the [README](https://github.com/shuricksumy/tunnelward#quick-start-docker).
