**Tidier lists.** The Network and Tools pages read more evenly, on a computer and on a phone.

## Network page

- **One tag per line** in *Reaches*, *Behind it* and (WireGuard) *Sends*: a column's tags share
  its width and line up from row to row.
- **Long lists fold**: more than five show the first four and *+N more*, which opens the row.
- **LANs behind a client** have their own green look; the legend under the table explains it.
- **Phones**: each client card lines every value up next to its label (the *VPN address* cell
  no longer spills).

## Tools page

- **Suggestions grouped**: Server, Connected, LANs behind clients, DNS, Internet.
- Each is a **button of the same size**, the name on the left and the address on the right;
  the gateway of a LAN is named after its named network when it has one. The one you picked
  is marked.

## Upgrading from 0.6.0

`docker compose pull && docker compose up -d`. Only the web UI changed; nothing to set.
